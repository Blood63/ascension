Confidentialité & mentions

Dernière mise à jour : 21 novembre 2026 · Version du jeu 0.19.3 · Application Android fr.ascension.jeu (versionCode 95)

Le jeu Ascension, créé par Émilien Lardeux, est un jeu de randonnée pixel jouable sans compte — dans le navigateur, en application web (PWA), via un fichier HTML unique, ou via l’application Android distribuée en fichier .apk.

Aucune collecte, aucun cookie, aucun suivi

Aucune donnée personnelle n’est collectée, transmise ou vendue. Ce site et le jeu n’embarquent pas de publicité, pas d’outil d’analyse d’audience, pas de compte utilisateur et pas de serveur de sauvegarde. Aucun cookie de mesure ou de publicité n’est déposé. Le stockage utilisé est uniquement local, sur ton appareil.

Sauvegarde sur l’appareil

La progression (niveaux terminés, meilleurs temps, étoiles, objets du carnet, personnage, réglages de volume et de vibrations) est enregistrée uniquement sur l’appareil — dans le stockage local du navigateur ou de l’application. Cette sauvegarde ne quitte l’appareil que si tu utilises toi-même la fonction « Exporter » des Réglages (fichier .json ou code commençant par ASC1-).

Autorisations de l’application Android

  • Vibrations : utilisées uniquement pour le retour haptique en jeu, si tu les laisses activées dans les Réglages. Rien n’est envoyé à l’extérieur.
  • Internet : l’application peut déclarer cette autorisation du fait de son composant d’affichage (WebView). Le jeu lui-même ne s’en sert pas pour transférer des données personnelles et fonctionne hors ligne.

Site officiel et application web

Le site est entièrement statique. Un service worker peut mettre en cache les pages et les fichiers du jeu sur ton appareil, afin que tu puisses rejouer hors-ligne après une première visite. Les fichiers d’installation (APK, HTML autonome) ne sont pas mis en cache par ce mécanisme, pour ne pas saturer le stockage.

Enfants

Le jeu ne s’adresse pas à la collecte de données d’enfants, puisqu’il n’en collecte aucune.

Contact

Pour une question sur cette politique, contacte l’éditeur du jeu, Émilien Lardeux. Lorsqu’une fiche store sera publiée, elle pourra aussi servir de point de contact.
